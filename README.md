# Trellis

A header-only C++20 dependency injection library. **Pre-alpha: nothing usable yet.**

- [`docs/plan.md`](docs/plan.md): the design and implementation plan.
- [`research/`](research/README.md): the background research the plan is based on. It covers existing C++ DI frameworks, hands-on compile-time, runtime and diagnostics measurements, and the benchmark harness that produced them.

Phase 0 (foundations) is starting.
